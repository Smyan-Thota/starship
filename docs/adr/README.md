# Architecture Decision Records

One file per decision. The filename `YYYY-MM-DD-slug.md` is the record's ID. The template for a new record is `engine/templates/ADR.md`. `docs/templates/ADR.md` is the original it comes from.

## Status

| Status | Meaning |
| --- | --- |
| Proposed | Open for the owner to accept or reject. |
| Accepted | Agreed. The file is now immutable. |
| Rejected | Declined. The reason is written under Decision. |
| Superseded | Replaced by a later record named in `Superseded by`. |

## How these six stand

All six records are Proposed. Only the owner accepts a decision. The code follows the six as they stand. When the owner accepts or rejects a record, its status changes in the index. A change to an accepted decision is a new record and a new task.
